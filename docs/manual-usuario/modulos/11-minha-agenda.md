# Minha Agenda

**Menu:** Profissionais → Minha Agenda  
**Endereço na barra de endereços:** `/minha-agenda`  
**Quem usa:** Terapeutas.

## Para que serve

Sua agenda pessoal de consultas (somente os seus horários).

## Como chegar

1. Faça login no sistema.
2. No menu à esquerda, abra o grupo indicado em **Menu**.
3. Clique em **Minha Agenda**.

## Tela principal

![Tela Minha Agenda](manual-usuario/screenshots/profissionais/minha-agenda.png)


## O que você pode fazer

- Ver consultas do dia/semana.
- Abrir detalhe do agendamento.

## Dicas

- É a mesma base de **Agendamentos**, filtrada para o profissional logado.
