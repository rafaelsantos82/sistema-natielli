# Dashboard

**Menu:** (página inicial após login)  
**Endereço na barra de endereços:** `/`  
**Quem usa:** Todos os perfis com acesso ao sistema.

## Para que serve

Visão geral do dia: resumos, atalhos e indicadores da unidade selecionada.

## Como chegar

1. Faça login no sistema.
2. No menu à esquerda, abra o grupo indicado em **Menu**.
3. Clique em **Dashboard**.

## Tela principal

![Tela Dashboard](manual-usuario/screenshots/geral/dashboard.png)


## O que você pode fazer

- Visualizar indicadores e cards de resumo.
- Acessar atalhos para áreas frequentes.
- Trocar de unidade no seletor do cabeçalho (quando disponível).

## Passo a passo comum

1. Confira no topo qual **unidade** está selecionada — muitas telas filtram por ela.

## Dicas

- Se os números parecerem vazios, verifique se a unidade correta está ativa.
