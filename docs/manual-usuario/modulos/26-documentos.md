# Documentos

**Menu:** Documentos → Documentos  
**Endereço na barra de endereços:** `/documentos`  
**Quem usa:** Toda a equipe (conforme permissão).

## Para que serve

Biblioteca de arquivos institucionais por categoria.

## Como chegar

1. Faça login no sistema.
2. No menu à esquerda, abra o grupo indicado em **Menu**.
3. Clique em **Documentos**.

## Tela principal

![Tela Documentos](manual-usuario/screenshots/documentos/documentos-arquivos.png)


## O que você pode fazer

- Upload de arquivo.
- Organizar categorias.
- Excluir arquivo obsoleto.

## Abas desta tela

### Aba «Arquivos»

Lista de documentos disponíveis.

### Aba «Categorias»

Pastas lógicas para classificar arquivos.


## Passo a passo comum

1. Envie arquivo e escolha categoria.
2. Baixe pelo botão na linha.
