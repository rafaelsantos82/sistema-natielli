# Controles de acesso

**Menu:** Administração → Controles de acesso  
**Endereço na barra de endereços:** `/configuracoes/controles-acesso`  
**Quem usa:** Somente administrador.

## Para que serve

Ajustar permissões finas por perfil (o que pode ver e fazer).

## Como chegar

1. Faça login no sistema.
2. No menu à esquerda, abra o grupo indicado em **Menu**.
3. Clique em **Controles de acesso**.

## Tela principal

![Tela Controles de acesso](manual-usuario/screenshots/admin/controles-acesso-api.png)


## O que você pode fazer


## Abas desta tela

### Aba «API (ações)»

Permissões de leitura/escrita na API.

### Aba «Escopo de dados»

Quais dados o perfil enxerga (ex.: só sua unidade).

### Aba «Menu»

Itens visíveis no menu lateral.


## Passo a passo comum

1. Selecione o perfil.
2. Marque ou desmarque permissões.
3. Salve alterações.
