# Documentos Assinados

**Menu:** Clínico → Docs Assinados  
**Endereço na barra de endereços:** `/documentos-assinados`  
**Quem usa:** Profissionais e gestores.

## Para que serve

Documentos assinados digitalmente com validade no sistema.

## Como chegar

1. Faça login no sistema.
2. No menu à esquerda, abra o grupo indicado em **Menu**.
3. Clique em **Documentos Assinados**.

## Tela principal

![Tela Documentos Assinados](manual-usuario/screenshots/clinico/docs-assinados.png)


## O que você pode fazer

- Listar documentos assinados.
- Assinar novo documento (com chave digital cadastrada).
- Baixar ou verificar assinatura.
